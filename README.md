# COVID-19 Data Analysis using PySpark

## Overview
This project performs large-scale COVID-19 data analysis using **PySpark** to process, transform, and visualize pandemic-related datasets. The analysis focuses on understanding global and country-level trends in confirmed cases, deaths, recoveries, testing patterns, vaccination progress, and severity classification.

The project demonstrates the use of distributed data processing concepts in Apache Spark while applying practical data engineering and analytical workflows on real-world healthcare datasets.

---

## Objectives
- Analyze worldwide COVID-19 trends using PySpark
- Perform data cleaning and preprocessing on large datasets
- Generate statistical insights from pandemic data
- Build transformations and aggregations using Spark DataFrames
- Visualize trends and comparisons using charts
- Apply feature engineering techniques for severity analysis
- Understand Spark architecture and distributed computation

## Key Analysis Performed

### Data Cleaning & Preprocessing
- Handling missing and null values
- Type conversion and schema correction
- Filtering inconsistent records
- Standardizing date formats

### Exploratory Data Analysis
- Country-wise confirmed cases
- Death and recovery analysis
- Daily and monthly trend analysis
- Active case computation
- Top affected countries comparison

### Time Series Analysis
- Growth of confirmed cases over time
- Daily new cases and death trends
- Pandemic peak identification
- Rolling averages and trend smoothing

### Statistical Insights
- Mortality rate calculation
- Recovery rate analysis
- Country ranking based on cases and deaths
- Comparative statistics between regions

### Feature Engineering
- Severity classification:
  - Low
  - Medium
  - High
  - Critical
- Categorization using PySpark `when()` transformations

### Spark-Based Processing
- Distributed DataFrame operations
- Aggregations using `groupBy`
- Window functions
- Optimized transformations and actions
- Spark SQL queries
